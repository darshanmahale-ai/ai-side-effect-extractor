# AI-Powered Side Effect Extractor

## Project Overview
Automated extraction of Drug, Side Effect, and Severity from clinical case reports.

## How to Run
1. pip install -r requirements.txt
2. python generate_data.py
3. python -m streamlit run app.py

## Features
- Extracts 100 reports automatically
- Shows charts of side effects
- Downloads results as CSV

## Tech Used
Python, Pandas, Regex, Streamlit
